# Oriyali coloured-pencil animation assets

Generated with the built-in image-generation tool on 2026-09-05. Full source PNGs remain in the Codex generated-images directory; these WebP files preserve their composition and, for the bloom, alpha transparency.

- `cycle-pencil-atlas.webp`: six aligned 16:9 panels in a 3×2 atlas. First light → morning → noon → golden hour → dusk → blue hour. Scrolling develops one drawing into the next: sky, sun, mist, flowers and butterfly all change together.
- `bloom-pencil-atlas.webp`: three square flower states across two rows. The second row is an alternate drawing, mixed at low opacity for a slight pencil flicker. Energy opens the flower; mood changes its warmth; irritability changes the small registration variation and timing.
